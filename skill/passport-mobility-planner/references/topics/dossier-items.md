# Dossier items

The supporting documents visa, residence and settle-in applications ask for. The item names match the required documents lists in the option and settle-in files.

## Contents

- Item types and fields
- Age limits used for flags

## Item types and fields

| Item | Fields to extract |
| --- | --- |
| birth-certificate | full name, date and place of birth, parents names, registry number, issuing office, issue date |
| marriage-certificate | both spouses names, date and place of marriage, registry number, issuing office, issue date |
| degree-certificate | holder name, institution, degree, field, award date |
| transcript | holder name, institution, programme, period, issue date |
| cv | name, current role, employers with start and end dates |
| employment-letter | employer, holder name, job title, start date, salary and currency if stated, letter date, signatory |
| employment-contract | employer, holder name, job title, start date, end date, salary and currency, work country |
| payslips | employer, holder name, pay period, gross and net pay, currency |
| bank-statements | holder name, bank, last three characters of the account, currency, period start and end, opening and closing balance, issue date |
| tax-return | holder name, tax year, country, taxable income, filing date |
| business-registration | business name, registration number, country, owners or directors, registration date, status |
| sponsor-letter | sponsor name, relation, what is covered, amount if stated, date |
| invitation-letter | inviter, guest name, purpose, dates, address, date of letter |
| police-clearance | holder name, issuing authority, country, issue date, result |
| medical-certificate | holder name, issuing clinic, tests done, result, issue date |
| health-insurance | insurer, insured names, cover period, territory, cover amount |
| travel-insurance | insurer, insured names, cover period, territory, medical cover amount |
| flight-booking | passenger names, route, dates, booking reference shown masked to its last three characters |
| accommodation-proof | guest names, address, dates, host or hotel |
| tenancy-contract | tenant and landlord names, address, start and end dates, monthly rent, deposit, registration number if any |
| proof-of-income | source, holder name, amount, period |
| national-id | as a residence permit in the document fields reference |
| passport-photo | file date; photos older than six months fail most photo rules |

Anything else goes under other, named as printed.

## Age limits used for flags

Authorities set their own limits; use the one in the matching option or settle-in step when it gives one. When none is given, flag for checking, not as a failure:

- police clearance and medical certificate issued more than 3 months ago;
- bank statements whose period ended more than 1 month ago, or covering fewer than 3 months;
- payslips older than 3 months;
- passport photos taken more than 6 months ago.

## Attestation, apostille and translation

Many countries accept foreign certificates only when legalised: an apostille for countries in the Hague Apostille Convention, or embassy and foreign ministry attestation otherwise. Several Gulf countries also require attestation for degree and marriage certificates used for work or family residence. Record what is visible on the scan: an apostille certificate, attestation stamps, a sworn translator stamp. Say "not visible" rather than "not done": the stamp may be on a page that was not scanned.

## Names across documents

Compare every supporting document with the passport name. Common differences: middle name missing, maiden and married names, different transliteration, swapped surname and given names. Report each difference; some authorities ask for a one-and-the-same-person affidavit or a marriage certificate to link names.
