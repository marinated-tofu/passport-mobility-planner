# Benefits route

Matches what each traveller holds against the official rules, researched today.

## Build the holdings

For each traveller, from the verified dossier:

- passports: nationality (three-letter code converted to the two-letter code), date of expiry;
- visas: issuing country, visa type, entries, valid until;
- residence permits: issuing country, valid until, occupation if printed.

Only documents valid today count. Note any that expire within 12 months.

## Research the rules

Follow research.md with topic entry. Countries: the ones the user asked about; when they asked "where can I go" without naming any, use topic index with countries ALL, and add a second request with topic entry for the countries whose visa or residence permit the travellers hold, since many countries let holders of those in.

## Match each rule

From the excerpts, write each rule as what it gives (stay, purpose) and what must hold for it ("unlocked by"). For each rule:

1. Skip it when the excerpts exclude the traveller's nationality, or list "only for" nationalities that do not include it.
2. Mark it **Unlocked** when every condition is met by a document valid today.
3. Mark it **Needs checking** when every condition is met except one the documents cannot show, for example "visa must have been used once", "multiple-entry only" when entries are unreadable, an age limit when the date of birth is missing, or a profession list when no occupation is printed. Name the condition.
4. Otherwise leave it out.

For each unlocked rule, find the date the benefit is lost: the earliest expiry among the documents that unlock it. If that is within 12 months, say so.

## Rank and present

1. Unlocked benefits that will be lost soonest.
2. Other unlocked benefits, by country name.
3. Needs checking.
4. From the passport index only: destinations it lists as visa-free or visa on arrival, marked "from the passport index, confirm on the official page".

Show the stay length and purpose exactly as the excerpt states them, with the page address and fetched date.

Never combine rules into a benefit no excerpt states, and never say a traveller needs no visa for a country unless an excerpt says so for their documents, or the passport index does and it is marked as such. For a country the research did not cover, say so and point to its entry in official-sources.md.
